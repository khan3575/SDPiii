# SDP III

Django blog/social platform built for a "Software Development Project 3" university course — custom user accounts, blog posts, comments, reactions, and following other users.

## Features

- Custom user model with address info
- Blog posts with comments and reactions
- Follow system between users
- Activity log

## Tech stack

Python, Django

## Getting started

```bash
pip install -r requirements.txt   # note: no requirements.txt is currently committed
python manage.py migrate
python manage.py runserver
```
